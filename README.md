# Wisp SMP Datapack

The Wisp SMP Datapack is a comprehensive Minecraft datapack designed to enhance your server with a variety of features and commands. It includes every command block item available in Minecraft, providing a wide range of functionalities to customize and expand your gameplay experience. This datapack is perfect for server administrators looking to add unique features to their Wisp SMP server.

## Install

1. Download the datapack from the GitHub repository.
2. Place the datapack file in the `datapacks` folder of your Minecraft server.
3. Start or reload your Minecraft server to apply the datapack.

## Use

1. Join your Minecraft server.
2. Use the various commands provided by the datapack to interact with the enhanced features.
3. Explore the new functionalities and customize your gameplay experience.
